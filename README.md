# Software FJ - Sistema Integral

Sistema en Python orientado a objetos para gestionar clientes, servicios y reservas.

Servicios:
- Reserva de salas
- Alquiler de equipos
- Asesorias especializadas

Incluye:
- Clases abstractas, herencia y polimorfismo
- Encapsulacion en Cliente
- Excepciones personalizadas
- Archivo de logs (logs.txt)
- 10 operaciones de prueba

Como ejecutar:
python main.py
